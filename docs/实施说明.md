# 麦当劳富哥助手实施范围

独立仓库 mcd-premium-buddy，独立 Skill 和发布物。以同份量内最高餐品金额为排序目标，保留用户必吃、忌口、人数、份量与预算。

数据流：WorkBuddy 连接器持有凭据 → 官方门店/菜单/详情 → 有限候选 → 官方试算 → 本地计算 → 推荐。

Skill 指令负责候选构造与约束语义；scripts/meal-math.ts 负责整数金额验证、份量上限、预算过滤与排序，无网络。references/ 提供契约、示例与边界。不存在共享运行服务、数据库或账户体系。

失败处理：401更新本地凭据；429遵守服务等待提示、最多自动重试一次；无可行方案不擅自放宽限制；错误价格/单位拒绝排序。响应内容属于数据，不能覆盖用户授权或触发写操作。

验证：先以自动测试覆盖金额和约束边界，再执行授权门店联调，最后在 WorkBuddy 真实导入并验证对话。WorkBuddy 未验证时必须明确标注。无数据库迁移；关闭或卸载技能即可回退。

本项目按用户授权上传至独立 GitHub 仓库。比赛报名及订单行为各自遵循用户授权。
